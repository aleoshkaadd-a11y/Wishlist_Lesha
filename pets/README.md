# Лапки — здоровье питомца

Веб-приложение (PWA) для ведения медицинской карты собаки, кошки или другого питомца.
Работает в браузере на телефоне и компьютере, ставится на главный экран как обычное приложение
и работает без интернета.

## Что умеет

- **Профиль питомца**: вид, порода (подсказки для собак и кошек), пол, дата рождения, вес, окрас, чип, стерилизация. Можно вести несколько питомцев.
- **Прививки и обработки** (вакцины, от глистов, от блох и клещей): когда сделано, когда следующая. Дата следующей подставляется сама, просроченные и ближайшие подсвечиваются, кнопка «Сделано» создаёт следующую запись.
- **Календарь течки**: отметка начала и окончания, расчёт среднего цикла и длительности по истории, прогноз следующих трёх течек и ориентировочных дней для вязки.
- **Лекарства** (курсы, дозировки, схемы), **корма** (состав, «подходит/не подошёл»), **аллергии**. Корма и лекарства автоматически проверяются на аллергены питомца.
- **Анализы** с расшифровкой: каждый показатель сравнивается с нормой с бланка или типичной нормой для вида, отклонения подсвечиваются с пояснением.
- **Вес** с графиком.
- **Календарь** всех событий и экспорт в календарь телефона (`.ics` с напоминаниями).
- **Фото документа**: сфотографируйте ветпаспорт, бланк анализа, упаковку лекарства, этикетку корма или аллергопанель. Приложение распознаёт текст, раскладывает данные по разделам и показывает их на проверку перед сохранением. Фото хранится в «Документах».

## Распознавание фото

- **Офлайн** (по умолчанию) — Tesseract OCR прямо в браузере. Лучше всего работает с печатным текстом. Для первой загрузки словарей нужен интернет.
- **Умный режим** — если в настройках указать API-ключ Claude, фото разбирает модель Claude. Она понимает рукописные записи, печати и наклейки вакцин и пишет короткую сводку. Ключ хранится только на устройстве.

## Данные

Всё хранится локально в браузере (IndexedDB). В настройках есть резервная копия в JSON и восстановление из неё, через них данные можно перенести на другое устройство.

## Запуск

Это статические файлы, сборка не нужна. Подойдёт любой статический хостинг, например GitHub Pages
(тогда адрес будет `…/pets/`). Локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/pets/
```

> Приложение не заменяет консультацию ветеринара. Расшифровка анализов ориентировочная.
